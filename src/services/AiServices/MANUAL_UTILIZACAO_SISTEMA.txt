1. INTRODUÇÃO AO SISTEMA
================================================================================

O Compuchat é uma plataforma completa de atendimento via WhatsApp que permite
gerenciar conversas, automatizar respostas, criar campanhas e muito mais.

PRINCIPAIS FUNCIONALIDADES:
- Atendimento de conversas do WhatsApp
- Dashboard com métricas e estatísticas
- Automação com Flow Builder
- Campanhas de envio em massa
- Integração com IA (OpenAI, Gemini)
- Formulários personalizados
- Gestão de contatos e filas
- Sistema de tags e classificação

ACESSO AO SISTEMA:
- URL: Acesse através do navegador web
- Login: Use email e senha cadastrados
- Recuperação de senha: Use o link "Esqueci minha senha"

2. ATENDIMENTOS (TICKETS)
================================================================================

O QUE SÃO TICKETS?
Tickets são conversas de atendimento que chegam via WhatsApp. Cada conversa
com um cliente gera um ticket no sistema.

ABAS DE ATENDIMENTOS:
- ABERTOS: Tickets em atendimento ativo
  * Conversas: Conversas individuais com clientes
  * Grupos: Conversas em grupos do WhatsApp
- AGUARDANDO: Tickets pendentes de aceitação
- RESOLVIDOS: Tickets finalizados
- BUSCA: Buscar tickets por palavra-chave

COMO FUNCIONA O FLUXO DE ATENDIMENTO:

1. NOVO TICKET:
   - Cliente envia mensagem no WhatsApp
   - Ticket aparece na aba "Aguardando"
   - Para grupos: ticket vai direto para "Abertos > Grupos"

2. ACEITAR TICKET:
   - Clique no botão "Aceitar" no ticket
   - Ticket muda para status "Aberto"
   - Você se torna responsável pelo atendimento
   - Mensagem automática pode ser enviada (se configurado)

3. ATENDER:
   - Digite mensagens no campo inferior
   - Envie texto, imagens, áudios, documentos
   - Use mensagens rápidas para respostas comuns
   - Adicione tags para classificar

4. FINALIZAR:
   - Clique em "Finalizar" quando resolver o problema
   - Ticket vai para "Resolvidos"
   - Pode ser reaberto se necessário

AÇÕES DISPONÍVEIS EM TICKETS:

- ACEITAR: Assumir responsabilidade pelo ticket
- FINALIZAR: Encerrar o atendimento
- REABRIR: Voltar um ticket resolvido para aberto
- TRANSFERIR: Passar ticket para outro atendente ou fila
- RETORNAR: Voltar ticket para "Aguardando"
- ADICIONAR TAG: Classificar o ticket
- CRIAR TAREFA: Criar tarefa relacionada ao contato
- AGENDAR: Agendar retorno ou compromisso
- MENSAGEM RÁPIDA: Enviar resposta pré-configurada

COMO CRIAR NOVO TICKET MANUALMENTE:
1. Clique no botão "+" na tela de atendimentos
2. Selecione ou crie um contato
3. Escolha a fila (se aplicável)
4. Clique em "Criar"
5. O ticket será aberto automaticamente

MENSAGENS INTERNAS:
- Mensagens internas são anotações que NÃO são enviadas ao cliente
- Aparecem com badge amarelo "INTERNA"
- São assinadas com o nome do usuário responsável
- Úteis para comunicação entre atendentes

DIFERENCIAÇÃO DE MENSAGENS EM GRUPOS:
- Mensagens de clientes: Fundo branco, lado esquerdo
- Mensagens da empresa: Cores diferentes por atendente, lado esquerdo
- Cada número/atendente tem uma cor única para fácil identificação
- Borda lateral colorida ajuda a diferenciar

4. CONEXÕES WHATSAPP
================================================================================

O QUE SÃO CONEXÕES?
Conexões são números de WhatsApp conectados ao sistema para receber e enviar
mensagens.

COMO CONECTAR UM WHATSAPP:
1. Acesse "Conexões" no menu
2. Clique em "Nova Conexão"
3. Escaneie o QR Code com seu WhatsApp
4. Aguarde a conexão ser estabelecida
5. Status mudará para "Conectado"

STATUS DE CONEXÃO:
- Desconectado: Não conectado ao sistema
- Conectando: Processo de conexão em andamento
- Conectado: Funcionando normalmente
- Desconectado: Perdeu conexão (reconectar necessário)

MÚLTIPLAS CONEXÕES:
- Você pode ter vários números conectados
- Cada conexão pode ter configurações diferentes
- Útil para separar departamentos ou filiais

CONFIGURAÇÕES DE CONEXÃO:
- Nome da conexão
- Integração com IA (OpenAI/Gemini)
- Prompt personalizado
- Fila padrão

2. Clique em "Importar"

6. FILAS DE ATENDIMENTO
================================================================================

O QUE SÃO FILAS?
Filas organizam o atendimento por departamento, produto ou tipo de serviço.

EXEMPLOS DE FILAS:
- Suporte Técnico
- Vendas
- Financeiro
- Pós-venda
- Reclamações

COMO CRIAR FILA:
1. Acesse "Filas" no menu
2. Clique em "Nova Fila"
3. Defina nome e descrição
4. Configure horário de funcionamento
5. Adicione atendentes à fila
6. Salve

ATRIBUIR ATENDENTES:
- Cada fila pode ter múltiplos atendentes
- Atendentes podem estar em várias filas
- Tickets são distribuídos entre atendentes da fila

HORÁRIO DE FUNCIONAMENTO:
- Defina dias e horários de atendimento
- Fora do horário, tickets podem ir para aguardando
- Mensagens automáticas podem ser configuradas

INTEGRAÇÃO COM IA:
- Cada fila pode ter integração própria
- Prompt personalizado por fila
- Respostas automáticas configuráveis

11. FLOW BUILDER (AUTOMAÇÃO)
================================================================================

O QUE É FLOW BUILDER?
Sistema de automação que cria fluxos de conversa automáticos.

COMO FUNCIONA:
- Cliente envia mensagem
- Sistema identifica palavras-chave ou intenção
- Responde automaticamente conforme fluxo configurado
- Pode transferir para atendente quando necessário

TIPOS DE AÇÕES:
- INÍCIO: Ponto de partida do fluxo
- CONTEÚDO: Mensagem de texto
- MENU: Opções para cliente escolher
- RANDOMIZADOR: Escolha aleatória entre opções
- INTERVALO: Aguardar tempo antes de próxima ação
- TICKET: Criar ticket para atendimento humano
- PERGUNTA: Coletar informação do cliente
- OPENAI: Integração com ChatGPT
- TYPEBOT: Integração com Typebot

COMO CRIAR FLOW:
1. Acesse "Flow Builders" no menu
2. Clique em "Novo Flow"
3. Arraste ações para o canvas
4. Conecte as ações
5. Configure cada ação
6. Teste o fluxo
7. Ative quando pronto

PALAVRAS-CHAVE:
- Configure palavras que ativam o fluxo
- Pode ser palavra exata ou similaridade
- Múltiplas palavras-chave por fluxo

CONDIÇÕES:
- Se/Então baseado em respostas
- Direcionar fluxo conforme escolha do cliente
- Lógica condicional avançada

15. PERGUNTAS FREQUENTES
================================================================================

PERGUNTA: Como aceitar um ticket?
RESPOSTA: Na aba "Aguardando", clique no botão "Aceitar" no ticket desejado.
O ticket será atribuído a você e mudará para "Abertos".

PERGUNTA: Como transferir um ticket?
RESPOSTA: Abra o ticket, clique no menu (três pontos) e escolha "Transferir".
Selecione o usuário ou fila de destino.

PERGUNTA: Como criar mensagem rápida?
RESPOSTA: Acesse "Mensagens Rápidas" no menu, clique em "Nova Mensagem",
digite o texto e salve. Use variáveis como {{name}} para personalizar.

PERGUNTA: Como conectar WhatsApp?
RESPOSTA: Acesse "Conexões", clique em "Nova Conexão", escaneie o QR Code
com seu WhatsApp e aguarde a conexão.

PERGUNTA: O que são mensagens internas?
RESPOSTA: Anotações que não são enviadas ao cliente. Aparecem com badge
amarelo "INTERNA" e são assinadas com seu nome. Úteis para comunicação
entre atendentes.

PERGUNTA: Como criar fila de atendimento?
RESPOSTA: Acesse "Filas" no menu, clique em "Nova Fila", defina nome,
adicione atendentes e configure horário de funcionamento.

PERGUNTA: Como usar tags?
RESPOSTA: Abra um ticket, clique no botão de tags e selecione as tags
desejadas. Tags ajudam a classificar e organizar tickets.

PERGUNTA: Como criar campanha?
RESPOSTA: Acesse "Campanhas", clique em "Nova Campanha", selecione lista
de contatos, configure mensagem e agende o envio.

PERGUNTA: Como configurar IA?
RESPOSTA: Acesse "Configurações" > "Automação & IA", escolha o provedor
(OpenAI ou Gemini), cole sua chave de API e configure o prompt.

PERGUNTA: Como criar formulário?
RESPOSTA: Acesse "Formulários", clique em "Novo Formulário", adicione
campos, configure validações e ações, depois publique e compartilhe o link.

PERGUNTA: O que é Flow Builder?
RESPOSTA: Sistema de automação que cria fluxos de conversa. Cliente envia
mensagem, sistema responde automaticamente conforme fluxo configurado.

PERGUNTA: Como ver métricas no dashboard?
RESPOSTA: Acesse "Dashboard" no menu. Você verá cards com métricas principais,
gráficos e tabela de atendentes. Use filtros para mudar período.

PERGUNTA: Como buscar tickets?
RESPOSTA: Na tela de atendimentos, use a busca ou acesse a aba "Busca".
Digite palavra-chave, nome do contato ou número do ticket.

PERGUNTA: Como reabrir ticket resolvido?
RESPOSTA: Abra o ticket resolvido, clique no botão "Reabrir". O ticket
voltará para status "Aberto".

PERGUNTA: Como criar tarefa?
RESPOSTA: Abra um ticket, clique no menu e escolha "Criar Tarefa". Defina
título, descrição, prioridade e prazo.

PERGUNTA: Como agendar retorno?
RESPOSTA: Abra um ticket, clique no menu e escolha "Agendar". Selecione
data, hora e adicione observações.

PERGUNTA: Como importar contatos?
RESPOSTA: Acesse "Contatos", clique em "Importar", baixe o modelo Excel,
preencha com os dados e faça upload do arquivo.

PERGUNTA: Como criar usuário?
RESPOSTA: Acesse "Usuários" (apenas admin), clique em "Novo Usuário",
preencha dados, defina perfil e selecione filas de acesso.

PERGUNTA: O que são sub-abas em Abertos?
RESPOSTA: Na aba "Abertos" há duas sub-abas: "Conversas" (atendimentos
individuais) e "Grupos" (conversas em grupos do WhatsApp).

PERGUNTA: Por que grupos vão direto para Abertos?
RESPOSTA: Grupos são automaticamente abertos e vão direto para "Abertos >
Grupos", sem passar por "Aguardando", para facilitar o atendimento.

PERGUNTA: Como diferenciar mensagens em grupos?
RESPOSTA: Mensagens de diferentes atendentes da empresa aparecem com cores
diferentes. Cada número/atendente tem uma cor única para fácil identificação.

PERGUNTA: Como usar análise de IA?
RESPOSTA: Abra um ticket, clique no botão de IA (estrela) e escolha
"Analisar Conversa". Receba análise completa com pontos-chave e sugestões.

PERGUNTA: Como ver relatórios?
RESPOSTA: Acesse "Dashboard" para métricas gerais ou "Campanhas" > "Relatórios"
para dados específicos de campanhas. Use filtros de período.

PERGUNTA: Como configurar horário de funcionamento?
RESPOSTA: Acesse "Filas", edite a fila desejada e configure dias e horários
de atendimento. Fora do horário, tickets podem ir para aguardando.

PERGUNTA: Como usar Kanban?
RESPOSTA: Acesse "Kanban" no menu. Visualize tickets em colunas por tag.
Arraste e solte tickets entre colunas para organizar o trabalho.

PERGUNTA: Como criar lista de contatos?
RESPOSTA: Acesse "Listas de Contatos", clique em "Nova Lista", adicione
contatos manualmente ou importe de arquivo Excel.

PERGUNTA: Como ver histórico de mensagens?
RESPOSTA: Abra qualquer ticket para ver todo o histórico de mensagens
com o cliente, incluindo texto, mídias e anotações internas.

PERGUNTA: Como exportar dados?
RESPOSTA: Em várias telas há opção de exportar. Clique no botão de exportar
(geralmente ícone de download) e escolha formato (Excel, CSV, PDF).

PERGUNTA: Como configurar notificações?
RESPOSTA: Acesse "Configurações" > "Notificações". Configure alertas por
email, notificações no navegador, sons e preferências de notificação.

PERGUNTA: O que fazer se WhatsApp desconectar?
RESPOSTA: Acesse "Conexões", encontre a conexão desconectada e clique em
"Reconectar". Escaneie o novo QR Code se necessário.

PERGUNTA: Como usar busca avançada?
RESPOSTA: Na aba "Busca" dos tickets, use filtros por tags, usuários,
filas e período. Combine múltiplos filtros para busca precisa.

PERGUNTA: Como criar prompt personalizado?
RESPOSTA: Acesse "Prompts" no menu, clique em "Novo Prompt", defina nome,
escreva o prompt e associe a filas ou conexões específicas.

PERGUNTA: Como ver performance de atendentes?
RESPOSTA: No Dashboard, clique em um atendente na tabela para ver resumo
detalhado com estatísticas pessoais, tickets recentes e análise.

PERGUNTA: Como usar API de mensagens?
RESPOSTA: Acesse "Mensagens API" no menu. Veja documentação, gere token
de acesso e use endpoints para enviar/receber mensagens programaticamente.

PERGUNTA: Como configurar integração de pagamento?
RESPOSTA: Acesse "Configurações" > "Financeiro" ou "Integrações". Configure
provedor de pagamento (Mercado Pago, etc.) com credenciais necessárias.

PERGUNTA: Como usar chat interno?
RESPOSTA: Acesse "Chats" no menu. Crie conversas internas com outros
usuários da empresa para comunicação entre equipe.

PERGUNTA: Como criar anúncio?
RESPOSTA: Acesse "Anúncios" no menu, clique em "Novo Anúncio", defina
título, conteúdo, público-alvo e período de exibição.

PERGUNTA: Como ver arquivos enviados?
RESPOSTA: Acesse "Arquivos" no menu. Veja todos os arquivos enviados e
recebidos nas conversas, com opção de download.

PERGUNTA: Como usar agendamentos?
RESPOSTA: Acesse "Agendamentos" no menu. Crie compromissos, defina data/hora,
associe a contatos e receba lembretes.

PERGUNTA: Como criar template de mensagem?
RESPOSTA: Use "Mensagens Rápidas" para criar templates. Adicione variáveis
como {{name}} e {{ms}} para personalização automática.

PERGUNTA: Como ver relatório de campanha?
RESPOSTA: Acesse "Campanhas", clique na campanha desejada e depois em
"Relatório". Veja taxa de entrega, leitura, respostas e erros.

PERGUNTA: Como configurar resposta automática?
RESPOSTA: Configure Flow Builder ou integração com IA. Em "Filas", associe
Flow ou IA para respostas automáticas quando tickets são criados.

PERGUNTA: Como usar filtros no dashboard?
RESPOSTA: No Dashboard, use o dropdown de período (7 dias, 30 dias, etc.)
ou botão de filtro para personalizar período e métricas exibidas.

PERGUNTA: Como ver tickets por fila?
RESPOSTA: Na tela de atendimentos, use o menu de filtros (ícone de filtro)
e selecione filas desejadas. Apenas tickets dessas filas aparecerão.

PERGUNTA: Como marcar mensagem como lida?
RESPOSTA: Mensagens são marcadas como lidas automaticamente ao abrir o ticket.
Você pode ver status de leitura nos ícones de confirmação.

PERGUNTA: Como usar modo escuro?
RESPOSTA: O sistema detecta preferência do navegador automaticamente. Algumas
configurações podem estar em "Configurações" > "Aparência".

PERGUNTA: Como recuperar senha?
RESPOSTA: Na tela de login, clique em "Esqueci minha senha", informe seu
email e siga instruções recebidas por email.

PERGUNTA: Como ver estatísticas de formulário?
RESPOSTA: Acesse "Formulários", clique no formulário desejado e depois em
"Análise". Veja gráficos, respostas e métricas de conversão.

PERGUNTA: Como integrar com sistema externo?
RESPOSTA: Use Webhooks em "Configurações" > "Integrações". Configure URL
de destino e eventos que devem disparar webhooks.

PERGUNTA: Como usar botões de acesso rápido?
RESPOSTA: Configure em "Configurações" > "Botões de Acesso Rápido". Adicione
links para funcionalidades mais usadas que aparecerão no dashboard.

PERGUNTA: Como ver logs do sistema?
RESPOSTA: Logs geralmente estão disponíveis para administradores em
"Configurações" > "Logs" ou "Auditoria". Veja ações de usuários e eventos.

PERGUNTA: Como fazer backup?
RESPOSTA: Contate administrador do sistema. Backups geralmente são feitos
automaticamente pelo sistema ou podem ser solicitados ao suporte.

PERGUNTA: Como atualizar perfil?
RESPOSTA: Clique no seu nome/avatar no canto superior direito, escolha
"Perfil" ou "Configurações de Conta" e edite informações desejadas.

PERGUNTA: Como sair do sistema?
RESPOSTA: Clique no seu nome/avatar e escolha "Sair" ou "Logout". Você
será desconectado e redirecionado para tela de login.
